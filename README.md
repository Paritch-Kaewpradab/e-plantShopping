# e-Plant-Shopping
 
## Overview
- Basic shopping application built in React
- Includes basic functionality including
    - Adding items to cart
    - Adjust item quantity in cart
    - Price and total amount display in cart
- Final project for course 'Developing Front-End Apps with React'

## Layout
### About page
- Application information and texts

### Product Page
- Includes list of items with buttons for adding item to cart
- Only able to click once as the button is disabled upon added to the cart

### Cart Page
- List all items added to the cart
- Able to adjust quantity or removing specific item from the cart
- Display total amount and price of each item along with total checkout cost for all items 

### Navbar
- Includes logo, section (only plant), and cart icon that redirects to cart page view
- Cart item features display of different types of product added to the cart
